## Overview

Reselling involves more than buying low and selling high. You need to keep track of stock, purchase costs, shipping, platform fees, returns, and the actual profit generated by every sale.

**RESALEVAULT brings those operations together in one desktop application.**

Organize your inventory, understand your margins, prepare orders, generate labels, and review your financial performance without depending on a constant internet connection.

- **Local-first:** Your inventory and business data stay on your computer.
- **Real profit tracking:** Account for costs, fees, shipping, discounts, and returns.
- **Built for resellers:** Organize items, locations, purchases, and orders in one place.
- **Optional AI tools:** Generate listing descriptions using your own API key.
- **Privacy-focused:** No telemetry, analytics, or advertising, according to the project's privacy documentation.

## Features

### Inventory management

- Organize products with photos, categories, condition, tags, and storage locations.
- Track items using unique SKUs with check digits.
- Keep original media files and generated thumbnails organized.
- Find items and manage stock without relying on cloud storage.

### Purchases, orders & profit

- Record purchases and allocate costs across items.
- Track orders and calculate net profit.
- Account for platform commissions, shipping costs, discounts, and refunds.
- Analyze performance across time periods, sales channels, and categories.

### Order preparation

- Group items by storage location.
- Use scanning to verify items during order preparation.
- Keep fulfillment organized and reduce picking mistakes.

### Labels & codes

Generate printable labels using supported formats:

- Code 128
- Code 39
- EAN-13
- Data Matrix
- QR codes

### Financial reports

Understand how your reselling business is performing with reports covering:

- Profit over selected periods.
- Performance by sales channel and category.
- Inventory age and items that have remained unsold.
- Profit margins and pricing opportunities.

### Local intelligence

RESALEVAULT includes 12 local rules designed to flag potential issues, such as stagnant inventory, low margins, and opportunities to improve prices.

These rules run locally and do not require an AI service or internet connection.

### AI Studio — optional

Generate product listing descriptions using your own API key from a supported provider:

- Google Gemini
- OpenAI
- Anthropic

Your API usage is subject to the provider's terms and pricing. According to the project documentation, API keys are stored in the operating system's encrypted credential store rather than in the application database.

### Shipping Tracker

Access a directory of shipping carriers and track shipments through an integrated, isolated browser.

The tracker does not rely on scraping, according to the project's implementation documentation.

### Backups & data portability

- Create ZIP backups.
- Restore backups through a two-phase recovery process.
- Preserve the previous database during restoration.
- Import and export CSV files.

### Plans & licensing

RESALEVAULT supports Free, Pro, and Business plans, with plan limits enforced in the main application process.

**Your data is not deleted when a license expires.**

See the [plan comparison](docs/FREE-VS-PRO-VS-BUSINESS.md) for details.

## Privacy & data ownership

**Your inventory is yours. Your business data stays on your computer.**

RESALEVAULT is designed to operate offline for everyday inventory and order management.

According to the project's privacy documentation:

- No telemetry, analytics, or advertising.
- Inventory, orders, and customer records are not sent as part of license checks.
- Online license verification occurs only when a license is activated.
- License verification is not intended to block the application.
- Optional AI features use the provider and API key configured by the user.

AI providers may process the content submitted to their services under their own policies.

Read the full [Privacy Policy](PRIVACY.md).

### Windows security notice

The installer is not signed with a certificate trusted by Windows. Windows may therefore display an unknown-publisher warning or Microsoft Defender SmartScreen notice.

The project provides SHA-256 hashes for release artifacts so users can check file integrity.

To calculate a hash in PowerShell:

```powershell
Get-FileHash .\RESALEVAULT-Setup-0.5.0.exe -Algorithm SHA256
```

Compare the calculated hash with the value published for the corresponding release.

**Do not disable Windows security protections to install RESALEVAULT.** If you cannot verify an installer or are unsure about a security warning, do not proceed.

## Where your data is stored

RESALEVAULT stores its local application data under:

```text
%APPDATA%\RESALEVAULT\
├── data\
│   └── resalevault.sqlite    SQLite database and WAL files
├── media\                    Original photos and documents
├── thumbs\                   Generated thumbnails
├── backups\                  ZIP backups
└── logs\
    └── resalevault.log       Diagnostic log
```

Important details:

- Application data is separate from the installation directory.
- Updating the application does not intentionally replace your inventory.
- Core inventory functionality works offline.
- Uninstalling the application does not delete the data directory.
- You can remove your local data manually if you want to delete it permanently.

**Back up your data regularly**, particularly before upgrading or restoring a backup.

See the [Recovery Guide](docs/RECUPERACION.md) for backup and recovery instructions.

## Security architecture

The project documentation describes the following safeguards:

- Electron `contextIsolation: true`.
- Electron `nodeIntegration: false`.
- Electron `sandbox: true`.
- Explicitly declared IPC channels with validation in the main process.
- IPC access restricted to the main application window.
- Strict Content Security Policy, including a response header and a meta policy.
- Restricted navigation and new windows.
- External links limited to HTTPS.
- Parameterized SQL queries.
- Structured error codes that avoid exposing database queries or filesystem paths across the bridge.
- Credential-like fields redacted in diagnostic logs.
- Plan restrictions enforced in the main process rather than only by hiding interface controls.
- An isolated shipping browser without Node.js integration or preload scripts, with pop-ups, downloads, and permissions restricted.

The preload bridge is documented as exposing 158 specific IPC channels rather than a generic unrestricted invocation function.

For implementation details, review the source code and project documentation.

## Project structure

```text
src/
├── main/
│   ├── ipc/               IPC channels, validation, origin checks
│   ├── db/                SQLite, migrations, repositories
│   └── services/          Settings, backups, licensing, finance, AI, media
├── preload/
│   └── index.ts           Context bridge and IPC API
├── shared/                Types, Zod schemas, CSP, SKUs, plans, formats
└── renderer/
    └── src/               React user interface

tests/                     Automated tests
scripts/                   Diagnostics, packaging, benchmarks, licensing
docs/                      Manuals, reports, signing, licensing, privacy
```

### Database

The documented database implementation includes:

- 37 tables.
- Schema version 5.
- Enabled foreign-key constraints.
- Write-ahead logging (WAL).
- Monetary values stored as integer cents.
- ISO 8601 dates.
- UUID v4 identifiers.
